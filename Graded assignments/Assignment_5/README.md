# Inlämning 5 i DA281A

Enkel Vite + React setup, för mer information om hur projektet körs se text nedan:

## Utvecklingsläge
`npm install` - Installerar dependencies

`npm run dev` – Startar Vite-servern för utvecklingsmiljön

## Produktion
`npm install` - Installerar dependencies

`npm run build` – Använder Vite för att bygga projektet som lagras i distkatalogen

Ladda sedan upp filerna från distkatalogen till din webbserver och besök _index.html_.
